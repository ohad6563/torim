# תורים בקליק

אפליקציה לניהול תורים למספרות, קוסמטיקאיות, מעצבות גבות ומטפלות.
האפליקציה בנויה ב־Expo (React Native), כך שאותו קוד רץ בדפדפן, באייפון ובאנדרואיד. הנתונים נשמרים ב־Supabase.

## מה יש בגרסה הזו

**לבעל/ת העסק (עם חשבון):**
- הרשמה, התחברות ומחיקת חשבון
- הקמת עסק עם שירותים ושעות פעילות לדוגמה לפי התחום
- יומן שבועי: תורים לפי יום, צפי הכנסה, הוספת תור ידנית
- פרטי תור: חיוג, וואטסאפ, סימון ״הגיע/ה״ או ״לא הגיע/ה״, העברה למועד אחר, ביטול
- לקוחות: חיפוש, כרטיס לקוח עם היסטוריה, סטטיסטיקה והערות
- שירותים: משך, מחיר, הסתרה מהלקוחות
- שעות פעילות עם כמה טווחים ביום (הפסקות), חופשות וחסימות
- הגדרות הזמנה: מרווח בין שעות, זמן מינימלי מראש, כמה ימים קדימה

**ללקוחות (בלי חשבון), דרך הקישור `/b/<כתובת-העסק>`:**
- בחירת שירות, תאריך ושעה פנויה
- קביעת תור עם שם וטלפון
- דף ״התור שלי״ (`/a/<קוד>`) לצפייה, ביטול וניווט בוויז

תשלומים וסליקה יתווספו בשלב מאוחר יותר.

## הפעלה ראשונה

1. פותחים פרויקט חינמי ב־[supabase.com](https://supabase.com).
2. ב־Supabase נכנסים ל־**SQL Editor**, מדביקים את כל התוכן של `supabase/migrations/0001_init.sql` ומריצים.
3. מעתיקים את `.env.example` לקובץ חדש בשם `.env.local`, וממלאים בו את הכתובת ואת המפתח הציבורי (anon) מ־**Project Settings → API**.
4. מתקינים ומריצים:

```bash
npm install
```

```bash
npm run web
```

כדי לנסות על הטלפון מתקינים את אפליקציית **Expo Go** ומריצים `npm start`.

> כברירת מחדל Supabase דורש אישור אימייל אחרי הרשמה. בזמן פיתוח אפשר לכבות את זה ב־**Authentication → Providers → Email → Confirm email**.

## מבנה הפרויקט

```
src/app/            מסכים (כל קובץ הוא נתיב, Expo Router)
  (owner)/          הלשוניות של בעל העסק: יומן, לקוחות, שירותים, הגדרות
  b/[slug].tsx      דף קביעת תור ללקוחות
  a/[token].tsx     דף ״התור שלי״ ללקוחות
src/components/     רכיבי ממשק משותפים
src/context/        התחברות ונתוני העסק
src/lib/            Supabase, תאריכים, הודעות שגיאה, קישורים
supabase/           מבנה מסד הנתונים, כללי אבטחה ופונקציות
```

הלוגיקה החשובה נמצאת במסד הנתונים: חישוב השעות הפנויות (`get_available_slots`), קביעת תור (`book_appointment`), ומניעת חפיפה בין תורים ברמת מסד הנתונים, כך ששני לקוחות לא יכולים לקבוע את אותה שעה גם אם הם לוחצים באותו רגע.

## לקראת החנויות

- `app.json`: שם האפליקציה, מזהה החבילה (`com.torimbeclick.app`, אפשר לשנות לפני הפרסום הראשון), ו־RTL קבוע.
- `eas.json`: פרופילים לבנייה בענן עם EAS (`npx eas-cli@latest build`).
- נשאר לעשות: אייקון ומסך פתיחה משלכם, מדיניות פרטיות, וחשבונות מפתח ב־Apple וב־Google.
