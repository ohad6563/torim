# עדכון גרסה ל־TestFlight: "הגבות של הילה"

**ל־Claude:** כל ההכנות כבר נעשו. אין צורך לקרוא את הקוד, להריץ בדיקות או לחקור את הריפו. פשוט מריצים את הפקודות לפי הסדר. השרת (Supabase) כבר מעודכן, כולל כל המיגרציות.

## פקודות

אם הריפו כבר נמצא במחשב:
```bash
cd torim && git pull
```

אם לא:
```bash
git clone https://github.com/ohad6563/torim && cd torim
```

```bash
npm install
```

בנייה והעלאה ל־TestFlight בפקודה אחת (הבנייה רצה בענן של EAS, כ־15–25 דקות):
```bash
npx eas-cli@latest build -p ios --profile production --auto-submit
```

- אם EAS שואל על התחברות לחשבון Apple או על certificates: לאשר את ברירות המחדל (Yes).
- מספר הגרסה עולה אוטומטית (`autoIncrement`), אין מה לשנות.
- כשההעלאה מסתיימת, הגרסה מופיעה ב־TestFlight אחרי כ־10–30 דקות של עיבוד אצל אפל.

## אם משהו נכשל

- **"Not logged in":** מריצים `npx eas-cli@latest login`, ואז שוב את פקודת הבנייה.
- **העלאה ל־App Store Connect נכשלה, אבל הבנייה הצליחה:**
  ```bash
  npx eas-cli@latest submit -p ios --latest
  ```
- **שגיאה אחרת:** לשלוח לאוהד את השורות האחרונות של השגיאה. לא לשנות קוד, `app.json` או `eas.json`.

## טקסט ל־"What to Test" ב־TestFlight

```
מה חדש:
• רשימת המתנה: ביום מלא או בחופשה אפשר להצטרף, ומקבלים התראה כשמתפנה תור. למנהלת יש לשונית "המתנה".
• שאלון "מה מתאים לי?" במסך הבית.
• תנאי שימוש, הצהרת נגישות ועמוד תמיכה, ואישור תנאים בכניסה הראשונה.
• קונפטי חדש, בחירת יום עם סימון שמחליק, וסרטון רקע.
```

## מה לבדוק אחרי ההתקנה

1. כניסה עם Google (או Apple), ואחריה מסך "שם + טלפון" עם תיבת אישור תנאים.
2. קביעת תור ← קונפטי ← התראת "התור נקבע ✓" תוך כדקה.
3. יום מלא ← "הצטרפות לרשימת ההמתנה" ← המנהל מקבל התראה ← ביטול תור באותו יום ← מגיעה התראת "התפנה תור!".
